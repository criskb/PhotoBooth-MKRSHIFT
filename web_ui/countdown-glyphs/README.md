# Countdown glyphs

Optional custom countdown glyphs for the booth overlay.

Drop files here with these exact base names:

- `5`
- `4`
- `3`
- `2`
- `1`

Supported file types (checked in this order):

- `.svg`
- `.png`
- `.webp`
- `.jpg`
- `.jpeg`

Examples:

- `3.svg`
- `2.png`

When a matching file exists, the countdown renders that image for the corresponding number.
If a file is missing, the app automatically falls back to the regular text number.
